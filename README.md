# Vaults
Create, manage and synchronize sets of encrypted file-contained partitions, with inner contents versioned with `Git`. 
When encrypted, the partition files can be distributed across machines with `rsync`.

## Why?
Store personal notes, essays and works of art and work on them on any of your Linux machines, then manage the synchronization.
Also because Haskell.

It is built around a workflow that encourages collaboration, but also mitigates an untrusted infrastructure.

DO NOT use this project to store your passwords or authentication secrets, it's not meant for that.

## Warning
This is fairly complete, but highly experimental software.
